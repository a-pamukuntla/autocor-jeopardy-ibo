What's The Question?

A real-time quiz game with live team buzzers. No server required — runs entirely on GitHub Pages with MQTT over WebSockets.

Pages
📺 Game Board 🔴 Buzzer 🔒 Answer Key ⚙️ Setup 🧪 Test Buzzers
How to Host
⚙️
Open Setup. Configure your teams and branding. Click Save & Publish Live.
📺
Open the Game Board on the projector. Open the 🔒 Answer Key on your private laptop.
🔴
Share Buzzer URLs (or QR codes) with each team. Use 🧪 Test Buzzers to verify connectivity first.
🎯
Click tiles to reveal questions. Teams buzz in, you judge. First buzz locks everyone else. Wrong answers allow steals.
How It Works
All pages communicate in real time via MQTT over WebSocket Secure (port 443). Works on enterprise WiFi with no special config. Each deployment is automatically isolated by hostname — run multiple games side by side.
Configuration is published as a retained MQTT message. Change teams or branding from the setup page and every connected screen updates instantly — no redeploy needed.
